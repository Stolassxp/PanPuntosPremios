# Pan, Puntos y Premios

Sistema web de pedidos y fidelización para un restaurante de sándwiches. Proyecto Final de Programación II, Universidad Mariano Gálvez.

## ¿Qué hace?

Gestiona clientes, productos e inventario con su historial de movimientos.
Toma pedidos con sándwiches, bebidas, acompañamientos y menús completos.
Cobra en efectivo o con tarjeta, con inventario y puntos consistentes mediante transacciones.
Acumula puntos por pedidos pagados y permite canjearlos por productos gratis.
Genera seis reportes en PDF.

Expone una API REST y una app web en Flutter para consultar el saldo de puntos.
Tecnologías

Java, Servlets y JSP (Jakarta EE 10), Apache Tomcat 10.1, MySQL 8 con JDBC y PreparedStatement, Maven, OpenPDF y Flutter (web). Arquitectura MVC con capas de modelo, DAO, servicio y controlador.
